# Локальна копія сторінки Agent

Запуск: двічі натисніть `start.cmd`. Потрібен Node.js (вже встановлений на цьому ПК).
Адреса: http://127.0.0.1:4313. Вікно сервера залишайте відкритим під час роботи.
Також можна відкрити `public/index.html` напряму, без сервера.

## Редагування

- `public/index.html` — усі блоки й тексти основної сторінки.
- `public/assets/` — локальні фотографії, іконки, шрифти й оригінальні стилі.
- `public/local.css` — наші зміни стилів.
- `public/local.js` — інтерфейс форми, таймер і слайдер.
- `public/policy-coding.html` — збережена оферта оригіналу; перед публікацією нового проєкту її потрібно адаптувати.

Вигляд, контент і адаптивні стилі збережено з оригіналу. Аналітика, Webflow, визначення IP і captcha не підключені. CSP дозволяє лише CRM-скрипт IntegraLeap, його стилі та запити до налаштованого обробника.

Форма передає заявки через IntegraLeap у налаштований CRM-обробник і після успішної реєстрації переводить користувача в чат-бот. Таймер запускається з 19 хвилин при відкритті сторінки. Відеоуроки на вихідній сторінці були рекламним блоком, а не вбудованими відеофайлами.

`mirror.py` та `asset-manifest.json` — матеріали одноразового перенесення з адресами джерел, не використовуються сайтом. Не запускайте `mirror.py` після редагування: він перезаписує HTML. Для перенесення на інший ПК достатньо всієї папки проєкту, для статичного хостингу — папки `public`.
