# Розміщення відео

Архів сайту навмисно не містить великий відеофайл, тому його розмір залишається меншим за 20 МБ.

Після розпакування сайту завантажте файл masterclass.mp4 окремо за адресою:

record/media/masterclass.mp4

Вебсервер або CDN має підтримувати HTTP Range-запити (206 Partial Content). Це дозволяє запускати та перемотувати відео без повного завантаження файлу.

Сторінка використовує звичайний HTML5-плеєр і не відкриває YouTube або інші сторонні сайти.
