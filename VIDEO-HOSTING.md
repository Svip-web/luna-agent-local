# Розміщення відео

Архів сайту навмисно не містить великий відеофайл, тому його розмір залишається меншим за 20 МБ.

Плеєр завантажує відео безпосередньо з нашої опублікованої копії на GitHub Pages:

https://svip-web.github.io/luna-agent-local/record/media/masterclass.mp4

Сторінка використовує звичайний HTML5-плеєр і не відкриває YouTube, GitHub або інші сайти. Відео відтворюється всередині сторінки та завантажується частинами через HTTP Range-запити (206 Partial Content).
