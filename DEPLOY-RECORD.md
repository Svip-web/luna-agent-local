# Розгортання сторінки `/record`

1. Додайте папки `record/` і `assets/` з архіву до статичної директорії чинного Vercel-проєкту `agenthub.academy`.
2. Переконайтеся, що файл сторінки знаходиться за шляхом `<static-root>/record/index.html`.
3. Опублікуйте чинний Vercel-проєкт і відкрийте `https://agenthub.academy/record/`.
4. Перевірте відтворення відео без переходу на GitHub або YouTube.
5. Тестову заявку в CRM створюйте лише з дозволу власника.

Відеофайл не входить до архіву: HTML5-плеєр завантажує його напряму з опублікованої копії на GitHub Pages. Повна інструкція для іншого AI знаходиться у `HOSTING-AGENT-INSTRUCTIONS.md`.
