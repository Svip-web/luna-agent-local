# Інструкція для AI: публікація сторінки запису

## Результат

Опублікувати готову статичну сторінку за точною адресою:

https://agenthub.academy/record/

Основний домен `agenthub.academy` уже працює на Vercel. Не створюй іншу адресу, піддомен або окремий домен. Сторінка має відкриватися саме через `/record/` із завершальним слешем.

## Що знаходиться в архіві

- `record/index.html` — сторінка;
- `record/record.css` — оформлення;
- `record/record.js` — плеєр, попап і форма;
- `record/media/masterclass-poster.webp` — обкладинка відео;
- `assets/` — локальні шрифти, іконки та бібліотека телефонного поля;
- `HOSTING-AGENT-INSTRUCTIONS.md` — ця інструкція.

Великий файл `masterclass.mp4` до архіву не входить. HTML5-плеєр уже посилається на готову копію:

https://svip-web.github.io/luna-agent-local/record/media/masterclass.mp4

Не завантажуй відео у Vercel, не вставляй YouTube iframe і не змінюй URL відео без прямої вказівки власника.

## Як встановити у чинний Vercel-проєкт

1. Відкрий репозиторій, з якого Vercel публікує `https://agenthub.academy/`.
2. Визнач статичну директорію проєкту. У Next.js/Vite це зазвичай `public/`.
3. Скопіюй папки `record/` і `assets/` з архіву всередину статичної директорії, зберігаючи структуру шляхів.
4. Якщо в проєкті вже є `assets/`, об'єднай папки без видалення наявних файлів.
5. Після копіювання файл сторінки має бути доступний як `<static-root>/record/index.html`.
6. Не перетворюй сторінку на React/Next-компонент, якщо Vercel уже коректно роздає статичний `index.html` для `/record/`.
7. Зроби звичайний production deploy чинного Vercel-проєкту.

Якщо фреймворк не віддає `record/index.html` за `/record/`, додай статичний rewrite `/record` → `/record/` або маршрут до цього файла. Не перенаправляй користувача на GitHub Pages.

## Важливі налаштування, які треба зберегти

- Відео відтворюється у нативному `<video>` на сторінці, без переходу на YouTube або GitHub.
- CSP уже дозволяє відео з `https://svip-web.github.io` через `media-src`.
- Форма надсилає заявку у чинну CRM через `https://mufiksoft.com/shopifyband/amo-panel/forms.php`.
- Назва угоди має залишитися точно: `Консультация  запись  ИИ Агенты` — між словами збережені подвійні пробіли.
- Продукт: `Vibe-coding`.
- Етап CRM: `105804123`.
- Теплота: `Теплый`.
- Теги: `запись;консультация`.
- Після успішного надсилання не повинно бути переходу в Telegram. У цьому ж попапі показується повідомлення про успішну заявку.

## Перевірка після публікації

1. Відкрий `https://agenthub.academy/record/` і перевір код відповіді 200.
2. Перевір desktop і mobile вигляд.
3. Натисни Play: відео має залишатися всередині сторінки, запускатися та перемотуватися.
4. Переконайся, що запит відео повертає `Content-Type: video/mp4`, `Accept-Ranges: bytes`, а Range-запит — статус 206.
5. Відкрий форму та перевір телефонне поле, але не створюй реальну тестову заявку без дозволу власника.
6. Якщо власник дозволив тест CRM, перевір, що заявка потрапила у правильну воронку, а після успіху з'явився внутрішній екран подяки без Telegram-редиректу.

Не змінюй тексти, дизайн, CRM-реквізити або відеопосилання під час завантаження архіву.
